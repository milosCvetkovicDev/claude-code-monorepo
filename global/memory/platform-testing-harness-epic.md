1. **Drift:** all 13 services wired in `apps/platform/`, but `docs/platform/README.md` says 4 (M1) and only **5 are in compose** (auth/tenant/user/trading/gateway). Trust the code.
2. **Gateway does NOT proxy yet** (`gateway/.../service-registry.ts` static, "Sprint 2+"). Business smoke goes **DIRECT** to each service with **header identity** (`x-tenant-id`/`x-user-id`/`x-user-roles`/`x-permissions`) — **no JWT downstream**; `TenantGuard` reads `x-tenant-id` and the tenant must EXIST + be active.
3. **Login** = `POST :3001/auth/login {email,password,tenantId(UUID)}` → httpOnly cookies **`__session`** + `__refresh_token` (argon2 verify); body `{data:{userId,sessionId}}`.
4. **Credentials minted ONLY** via PUBLIC `POST :3003/api/v1/invitations/accept {token,password}`. Tenant create (`/api/v1/tenants`) is SUPERADMIN-only; invite create is ADMIN-only → **first-admin chicken-and-egg = the Tier 0.5 gap (#1168)**: needs an admin-bootstrap seed (no auth seed exists today). Reference data self-seeds via `SeedService implements OnApplicationBootstrap` (`SEED_ON_BOOTSTRAP=true`+`SEED_TENANT_ID`; trading confirmed, tenant/user VERIFY).
5. Ports: accounting `config.PORT` default **3000 → set 3010 explicitly**; others have main.ts defaults (inventory 3006, commission 3012, notification 3020, document 3021, audit 3022, reporting 3023, ai 3024). Trading **`enableRelay:false` in dev** (events not published); ai-service is event-only/no REST.
