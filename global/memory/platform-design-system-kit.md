  **2026-06-29 — KIT USAGE gotchas (consuming @acme/ui in finance app pages; cost real bugs in #1459, will recur in #1460/#1464/#1465):**

- **DataTable column state does NOT re-sync with the `columns` prop.** It seeds `order`/`hidden`/sort into internal `useState` once (from `columns.map(c=>c.key)`) and `visibleColumns = order.map(find).filter(!hidden)` — so a column whose key isn't in the original `order` never renders. Two DataTables in mutually-exclusive tab panels (`tab==='a' ? <DataTable a/> : <DataTable b/>`) share a tree position → React **reuses ONE instance**, so panel A's column-order leaks into panel B and silently HIDES B's extra columns (real #1459 bug: products tab's order hid the groups tab's "ERP nominal" column). **Fix: distinct `key` per table** (`key="products"` / `key="product-groups"`) to force remount. Applies to any dynamic `columns`.
- **Querying kit DataTable in tests:** sortable headers render `<th><button aria-label="Sort by X"><span>{header}</span>…</button></th>` → `getByText('X')` fails ("broken up by multiple elements"); use `getByRole('columnheader', { name: /x/i })`. EmptyState renders BOTH title and description containing the phrase → a substring regex `getByText(/no foo/i)` matches 2 elements ("Found multiple"); use the **exact** title string `getByText('No foo')`. Conditional row actions: the kit `RowAction`/`rowActions` has NO per-row predicate (renders on every row → silent dead buttons); render a status-conditional **Actions column** with `render:(row)=> row.status==='OPEN' ? <Close/> : <Reopen/>` instead (PayoutsPage/AccountingMonths pattern).
- **`fmtNum` (from `@acme/ui/domain`) defaults to 0 dp** — `fmtNum(0.85)` → `"1"`. NEVER use it for exchange rates or precise decimals; render the raw string (rates/money are strings over the API anyway). A flawed house pattern (InvoiceDetailPage uses `fmtNum(Number(x))` 0-dp for unitPrice too) — don't copy it for sub-1 values.

- **Write/Edit tool decodes `\u`/`\t`/`\n`/`\0` JSON escapes into LITERAL control bytes in the file** — writing a regex char-class like `[\0- ]` or a test string `'jav\0ascript:'` lands a real NUL/control char in source (git flags the file **binary**; tests may still pass since the byte is functionally valid). Build control-char test inputs via `String.fromCharCode(n)` and char-class ranges via codepoint iteration, NEVER literal `\u`/`\0` escapes through the tool. Detect strays: `python3 -c "d=open(f,'rb').read();print(sum(1 for b in d if b<0x20 and b not in(9,10,13)))"`.
