**Key durable design decisions** (on main):

- Hostname precedence: custom-domain → subdomain → `?tenant=` 302 shim → apex. Base `acme-example.co.uk`, dev apex `dev.platform.acme-example.co.uk` (NEVER dead hostnames `platform-dev.acme-example.net` / `dev.platform.acme-legacy.co.uk` — CI `check-no-legacy-domain.mjs` greps charts/apps/libs/docs for `.acme-example.net`, intent-blind; even a "NOT these" comment fails it).
- **`x-resolved-tenant-id` header contract** (the expert-review CRITICAL): GATEWAY is SOLE trusted setter — strips any inbound copy on ALL routes (anti-spoof), sets from trusted host classification (incl. pre-auth `/api/v1/auth/handoff/exchange`); auth reads ONLY it, fails closed (401 HANDOFF_CODE_INVALID). Header literal duplicated in both services, not cross-imported.
- Gateway resolve cache = bounded LRU (max+TTL), `trustProxy:1`, custom-domain crosscheck via tenant-service `GET /internal/tenants/by-domain/:host` (+ `by-id/:id` for discovery enrichment), fail-CLOSED on resolver error for should-resolve hosts. `TenantDomain` VO (lowercase+DNS) normalizes domain at write boundary.
- **Discovery enumeration-safe**: rate-limit FIRST (per-email `discovery:{email}` 3/h + per-IP `discovery-ip:{ip}` 10/min), constant-work tail (lookup×1 + notify×1 ALWAYS, even 0 memberships), byte-identical 202. **Discovery notification is PLATFORM-scoped** (nil-UUID sentinel tenantId on the identity event so the tenant-scoped consumer never NACKs). SUPPRESSED-recipient check in the notification consumer/send path, never the request handler.
- SSO handoff: Lua single-use code ([[platform-azure-cache-redis-6-0-no-getdel]]), host-only cookies (NO `Domain=`), Referrer-Policy no-referrer + history scrub. SUPERADMIN mandatory MFA gated on `roles.includes('SUPERADMIN')`.
- FE #1596 **kit-first**: primitives (Monogram, DomainInput, WorkspaceCard, HandoffInterstitial + 6 glyphs) in `@acme/ui` first, screens are compositions. #1598 fixed the Vite FR14 Host bug (`changeOrigin:false`+`xfwd:true`) + beta tenant + BR10 email + mailpit.
