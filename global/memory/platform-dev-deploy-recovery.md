Investigating #669 (Platform production verification) on 2026-05-26 surfaced that the **dev-platform AKS deployment was Degraded across 5 independent layers**, none of which was the original "free CPU" framing. Each is a distinct gap; fixing CPU alone never would have helped.

**1. THE root of code staleness — broken deploy pipeline. ROOT CAUSE FOUND + FIXED (PR #944).** `platform-pipeline.yml` (the real deploy path since `platform-deploy.yml` was retired to a stub in #667) **failed at 0s on EVERY run** — GitHub reported "this run likely failed because of a workflow file issue" and created **0 jobs**. Cause: `_deploy.yml` lines 194 + 764 used the **`secrets` context inside `if:` conditionals** (`if: ${{ secrets.GITOPS_PUSHER_APP_ID != '' && ... }}`), introduced by **#827 (`237aa211`, 2026-05-20)**. The `secrets` context is **not permitted in `if:`** → GitHub rejects the workflow file at load time. Because `_deploy.yml` is in the dispatcher's `uses:` graph, GitHub validated it on EVERY push/PR/dispatch, so the whole pipeline died before any job — **no Platform images built since 2026-05-20**, every service frozen on `sha-34e7e05` (~161 commits behind main). **FIX (PR #944, branch `fix/platform-pipeline-secrets-in-if`):** hoist the two secrets to **job-level `env:`** (where `secrets` IS legal) and gate the `if:` on `env.` instead; secrets still consumed in the step `with:` blocks. **Verified:** actionlint clears the `context "secrets" is not allowed` errors; the PR's platform-pipeline run created **8 jobs (was 0)** with the pure-bash `resolve` job green. **Diagnostic tip:** a 0-job "workflow file issue" failure on a reusable-workflow dispatcher = run `actionlint` on the WHOLE `uses:` graph (dispatcher + every `_*.yml`), not just the changed file — the fault is usually in a called reusable. `secrets`-in-`if:` is the classic trigger. **MERGE GATED** on a concurrent GitHub-side **"Incident with Actions and Pages" (critical, 2026-05-26)** that failed ALL action downloads (`codeload.github.com`) repo-wide — every `uses:`-based job across every workflow was red in 3-4s while no-`uses:` jobs passed. Re-run #944 checks once GitHub recovers; merge unblocks B4 + B5 + ~161 commits of latent fixes.
